# 6. Чек-листы самопроверки

## 6.1. Ведомость объёмов работ — перед передачей в сметный отдел

- [ ] Титульный лист и основные надписи оформлены по ГОСТ Р 21.101-2020
- [ ] Указан шифр комплекта и марка раздела
- [ ] Перечень работ полный, включая демонтаж, погрузку и вывоз строительного мусора
- [ ] Наименования работ сформулированы так, что позволяют однозначно подобрать сметную норму
- [ ] Единицы измерения — по СН 528-80 и сопоставимы с единицами сметных норм
- [ ] По каждой позиции приведена формула расчёта с исходными размерами
- [ ] По каждой позиции есть ссылка на лист чертежа и (или) позицию спецификации
- [ ] Объёмы в ВОР совпадают со спецификациями того же комплекта
- [ ] Указаны условия производства работ, влияющие на коэффициенты (стеснённость, высота, действующее производство, зимние условия)
- [ ] Материалы с обобщённым наименованием в нормах конкретизированы в проекте (марка, тип, характеристики)
- [ ] ВОР подписана разработчиком и проверяющим, согласована ГИПом

## 6.2. Конъюнктурный анализ — перед подписанием заказчиком

**Полнота источников**

- [ ] По каждой позиции набрано требуемое количество цен: 3 — материальные ресурсы и прочие затраты; 2 — импортное оборудование и услуги перевозки; 2 ТКП — индивидуальные материалы и адаптированное оборудование; 1 — безальтернативный производитель
- [ ] При недоборе есть письмо заказчика об отсутствии требуемого количества цен
- [ ] Поставщики не аффилированы (проверено по ЕГРЮЛ)
- [ ] Поставщики из региона строительства; если нет — приведено обоснование и учтена доставка
- [ ] На одну позицию использовано не более одного счёта/счёта-фактуры

**Содержание обосновывающих документов**

- [ ] В каждом документе есть: наименование поставщика, ИНН, контакты, сайт, сведения об исполнителе, дата составления, срок действия цены
- [ ] Указано, учтены ли в цене НДС, перевозка, шефмонтаж, шефналадка
- [ ] Технические характеристики в КП полностью соответствуют спецификации проекта
- [ ] По ТКП: указаны единица измерения, валюта, курс пересчёта; документ заверен подписью и печатью
- [ ] По РКЦ: приложен комплект РКМ, документы заверены и соответствуют требованиям бухгалтерского учёта
- [ ] Документы из открытых источников подписаны уполномоченным лицом заказчика, приложены ссылка и дата фиксации

**Сроки**

- [ ] Все обоснования получены не ранее чем за 6 месяцев до даты определения сметной стоимости (12 месяцев — только для объектов с особым статусом)
- [ ] Срок действия ценовых предложений не истечёт до окончания экспертизы; при риске — запланирован пересбор

**Расчёт**

- [ ] Цены приведены к уровню цен составления сметной документации (индекс фактической инфляции / индекс по ГОСР)
- [ ] Выполнен пересчёт в единицу измерения проекта (графа 11)
- [ ] Начислены транспортные расходы (расчёт, а не «в цене»)
- [ ] Начислены ЗСР по верному нормативу: 2 % — материалы, 0,75 % — металлоконструкции, 1,2 % — оборудование
- [ ] ЗСР не начислены на воду, пар, электроэнергию, сжатый воздух
- [ ] Принята наиболее экономичная цена, выбор обоснован
- [ ] При двух уровнях цен базисная стоимость получена обратным счётом по п. 22

**Оформление**

- [ ] Использована действующая редакция формы Приложения № 1 (в редакции приказа № 30/пр), заполнены все 27 граф
- [ ] Заполнена шапка: объект, уровень цен, субъект РФ, ценовая зона
- [ ] Таблица подписана: составил / проверил / застройщик (технический заказчик)
- [ ] Обосновывающие документы скомплектованы с описью и сопоставимы с номерами строк таблицы
- [ ] Сумма позиций КА сходится со строкой, показанной отдельно в итогах ЛСР (п. 78)

## 6.3. Сметная документация — перед сдачей в экспертизу

**Комплектность**

- [ ] Сводка затрат (при необходимости), ССРСС, ОСР, ЛСР, СР
- [ ] Пояснительная записка
- [ ] Ведомости объёмов работ
- [ ] Обосновывающие документы, включая КА
- [ ] При корректировке — сопоставительные ведомости объёмов работ (Приложение № 12) и, по требованию заказчика, изменения стоимости (Приложение № 13)

**Реквизиты и методология**

- [ ] Указаны программный продукт, редакция сметных нормативов, приказы о дополнениях
- [ ] Указаны реквизиты письма Минстроя об индексах изменения сметной стоимости
- [ ] Указаны субъект РФ и ценовая зона
- [ ] Метод определения сметной стоимости соответствует требованиям для данного объекта
- [ ] Применена редакция Методики № 421/пр, действующая на дату определения сметной стоимости
- [ ] Реквизиты в шапках форм совпадают с пояснительной запиской

**Шифры и структура**

- [ ] Шифры присвоены по пп. 29–34: СР-1, ЛС-02-01-01, ОС-02-01, ССРСС
- [ ] Наименования и нумерация глав ССРСС соответствуют Положению № 87 и не изменены
- [ ] Приведены итоги по главам и по группам глав 1–7, 1–8, 1–9, 1–12
- [ ] Резерв средств на непредвиденные работы не превышает 2 % / 3 % / 10 % в зависимости от типа объекта и согласован заказчиком
- [ ] Резерв рассчитан от итогов глав 1–12 и показан отдельной строкой с распределением по графам 4–8
- [ ] НДС учтён за итогом сводного сметного расчёта

**Содержание**

- [ ] Объёмы в ЛСР соответствуют ВОР
- [ ] Коэффициенты условий производства работ обоснованы проектом или ПОС
- [ ] Стоимость ПНР определена по программе и графику, заверенным заказчиком; разделение «вхолостую»/«под нагрузкой» выполнено по Приложению № 8
- [ ] Стоимость материалов и оборудования по КА показана в итогах отдельно

**Формат сдачи**

- [ ] Документы выгружены в XML по актуальным схемам Минстроя (ЛСР, ОСР, ССРСС, сводка затрат, КА)
- [ ] XML сформирован средствами сметного ПО, без ручной правки
- [ ] Для документов без опубликованной XML-схемы использованы допустимые форматы по п. 3 Требований (приказ № 783/пр)
- [ ] Файлы подписаны электронной подписью в соответствии с требованиями площадки
