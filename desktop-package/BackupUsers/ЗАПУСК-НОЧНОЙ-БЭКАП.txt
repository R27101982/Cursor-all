Nightly queue of FreeFileSync batches (local time 00:00)

WHY PowerShell stays open
-------------------------
FreeFileSync shows a dialog (sync.ffs_lock access denied) and waits for OK/Ignore.
The runner waits for FreeFileSync, so PowerShell stays open until that dialog is closed.

FIX FreeFileSync batch (do once for each BatchRun*.ffs_batch)
-------------------------------------------------------------
1. Open the .ffs_batch in FreeFileSync
2. File -> Save as batch job, enable:
   - Auto-close
   - Minimize / silent if available
   - On errors: continue / ignore (not "show popup and wait")
3. Run the batch once manually under user "admin"
4. When lock warning appears: Ignore + "Do not show again"
5. Save the batch again
