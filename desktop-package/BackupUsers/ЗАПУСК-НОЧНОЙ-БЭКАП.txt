Nightly queue of FreeFileSync batches (local PC time 00:00)

1) Put all batch files in Documents, names like:
   BatchRunPotapov.ffs_batch
   BatchRunKartashov.ffs_batch
   BatchRunIvanov.ffs_batch

2) Copy Run-AllBackupBatches.ps1 to e.g.:
   C:\Users\admin\Desktop\BackupUsers\Run-AllBackupBatches.ps1

3) Edit inside the script if needed:
   $BatchDir  = folder with .ffs_batch
   $Filter    = BatchRun*.ffs_batch
   $FreeFileSync path

4) Task Scheduler (taskschd.msc) on LS1:
   - Create Task (not Basic)
   - General:
       Name: FreeFileSync Nightly Backups
       Run whether user is logged on or not
       Run with highest privileges = NO (unless you need it)
       User: admin  (same account that can open \\PC\shares / has cmdkey saved)
   - Triggers:
       Daily, start 00:00:00, enabled
   - Actions:
       Program: powershell.exe
       Arguments:
         -NoProfile -ExecutionPolicy Bypass -File "C:\Users\admin\Desktop\BackupUsers\Run-AllBackupBatches.ps1"
   - Conditions:
       optional: Start only if network available
   - Settings:
       Run task as soon as possible after a scheduled start is missed = YES
       If the task is already running = Do not start a new instance

5) Test: right-click task -> Run
   Logs: %USERPROFILE%\Documents\BackupBatchLogs\run_*.log

Batches run one after another (queue), not in parallel.
